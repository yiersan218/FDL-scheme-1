# 无通信压缩：五档缺失率、五种子重复实验

- 算法：当前 `completion-v1`，矩阵变体 `completed`。
- 数据集：ALOI_100、animal、flower17、LandUse_21、Mfeat、NUSWIDE、Scene-15。
- 缺失率：0、0.1、0.3、0.5、0.7。
- 随机种子：42、2024、2025、2026、2027。每个数据集和缺失率组合独立运行 5 次，共 175 次。
- 通信：`compression.method=none`，`error_feedback=false`，完整共享参数上传。
- 模型、损失权重、轮数和本地训练配置来自当前 `config/*.json`，未为缩短运行而降配；实际展开后的配置见 `plan.json`。
- 补全：开启补全自监督和补全概率融合；沿用矩阵协议，统一采用观测初始化（`use_completed_initialization=false`）。该项与普通根配置的补全辅助初始化默认开关不同。
- 缺失率定义：选择约 `rate × 客户端样本数` 个不完整样本，每个样本恰好隐藏一个随机视图；并非视图单元格缺失比例。各任务保存实际掩码摘要。
- 所有缺失率使用客户端真实可见行归一化，使用同一模型和通信协议。

## 统计口径

对每个“数据集 × 缺失率”组合分别统计 5 次运行的 ACC、NMI、ARI。主表取每次运行在正式聚类阶段按 NMI 选中的同一最佳轮，三个指标不得各取不同轮的最大值。该选择使用标签指标；另列真实末轮统计。

均值为五次指标之和除以 5。主表方差为样本方差：五次指标与均值的平方偏差之和除以 4（`ddof=1`）。指标使用原始 0～1 比例尺度，方差保持该尺度的平方；ARI 可能为负值。统计工具同时保留总体方差（分母 5）以便核对。

## 文件

- `plan.json`：175 个任务的完整配置、输入文件哈希与源码指纹。
- `source_snapshot/`：计划对应的训练源码快照。
- `runs/`：每次运行的 `history.json` 与 `summary.json`。
- `summary.json`、`report.md`：矩阵入口生成的逐次结果。
- `statistics.md`、`statistics.json`：五次均值、方差及完成状态；仅全部 175 次通过核验后才是完整统计。
- `run_details.json`：统计使用的逐次指标与来源。
- `training.log`、`training_errors.log`：本批实验的标准输出和错误日志。
- `run_status.json`：后台执行状态。
- `run_experiments.ps1`：执行同一计划并在训练结束后自动统计；再次运行只复用完整且指纹相同的已有结果。

运行期间的部分统计必须明确标注未完成；少于 5 次的结果不得标作五次平均，单次结果的样本方差不设为零。
