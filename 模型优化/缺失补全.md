# 缺失视图协议与观测边界

当前 `completion-v1` 将缺失作为统一输入语义。固定mask描述哪些样本视图真实可见；补全可以改善预测，但不会改写mask。公式与流程见 [模型架构.md](D:/Project/Python/研究生毕设/FDL-scheme-1/模型架构.md)第3、5、8节。

## 1. 缺失生成

对客户端k的N_k个样本，选择 round(r*N_k) 个不同样本，每个恰好遮蔽一个随机视图。r属于[0,1)，至少两个视图；每行至少有一个观测。数据集名、seed、客户端ID与缺失率决定掩码，整个实验固定使用。

r是样本不完整比例，视图单元格缺失比例约为r/V。r=0产生全真mask；不同率的掩码不保证嵌套。

## 2. 归一化与批次

MAT先以none归一化读入，客户端只取每视图可见行计算统计；隐藏行写零占位。全真mask仍走相同本地预处理。编码器和观测原型头只接收真实行，解码保持batch形状但隐藏行不计重构损失。

整个客户端某视图完全无观测时会报错；单个batch无该视图观测可以跳过。当前主入口不自动接入真实外部mask、NaN或元素级缺失。

## 3. 监督边界

留一视图补全只对真实可见目标构造监督：排除目标视图的Query/Key、排除同ID锚点，以detach观测编码作教师。真正缺失值不进入重构、潜在监督、归一化或校准真值。

仅剩一个可见视图的样本没有可用跨视图监督，但仍能参与观测重构和聚类。完整样本提供跨视图预测训练；缺失不是另开一套损失的条件。

## 4. 预测与统计边界

正式概率包含有支持的补全估计；DEC教师仍由观测概率构造，真实原型中心均值/硬软计数只用真实行。completion字段不替换view_embeddings或mask。

| 环节 | 使用信息 |
|---|---|
| 观测重构 | 真实可见输入与其编码 |
| 补全MSE | 其他源视图预测＋真实可见教师 |
| DEC教师 | 轮初全部本地样本Qobs |
| 正式聚类学生 | Qobs与有支持的Qimp受限混合 |
| 初始化共同伪标签 | 观测或可选完成融合 |
| 中心均值与硬软计数 | 原mask真实观测 |
| 评估和压缩校准 | 同一mask、客户端预处理与补全上下文 |

## 5. 开启缺失率

当前root配置null默认rate=0、补全开启、压缩none。按现有配置覆盖 `missing.rate=0.3` 即运行缺失率0.3。旧 `missing.enabled=false` 仅表示有效rate0，不恢复全局预处理。

缺失与压缩独立，不要求Stage＋EF。比较缺失率影响时，各率应保持相同压缩选择和预算。旧结果目录不修改，新版本采用独立输出。
