# 当前模型的可选上行压缩

压缩与缺失率独立。`completion-v1` 默认不压缩；Stage＋客户端误差反馈是可选通信方法，完整和缺失场景均可使用。实现拆分为 [communication/codec.py](D:/Project/Python/研究生毕设/FDL-scheme-1/system/flcore/communication/codec.py) 与 [communication/compression.py](D:/Project/Python/研究生毕设/FDL-scheme-1/system/flcore/communication/compression.py)：前者负责共享参数范围、编解码、字节计量和共享状态恢复，后者负责候选评分、Stage 与 EF；[communication/__init__.py](D:/Project/Python/研究生毕设/FDL-scheme-1/system/flcore/communication/__init__.py) 为包入口，调用方按职责导入具体模块。模块拆分不改变下述协议和公式。

## 1. 更新与编码

客户端计算共享普通参数更新 \(\Delta=\theta_k-\theta_g\)。逐视图原型中心按独立通路处理；local补全参数不在共享参数坐标中。

启用EF后：

\[
u_t=\Delta_t+e_{t-1},\qquad c_t=\mathcal C(u_t),\qquad e_t=u_t-c_t.
\]

残差只在客户端保留。当前稀疏包包含12字节头，保留坐标各用4字节索引和4字节数值。预算B扣除头、中心、计数等固定开销F后，最多保留

\[
k=\min\left(n,\left\lfloor\frac{B-F}{8}\right\rfloor\right).
\]

实际预算比例是模型载荷字节比例，不是直接保留同样比例的参数。固定开销超预算应报错。

## 2. Stage校准与统一训练目标

客户端以本地校准样本比较候选，保持相同mask、本轮观测DEC目标，以及参考补全上下文。任务评分使用当前重构、补全、DEC、均衡四项目标；表示关系和聚类关系评分不读取真实标签。

稠密参考含EF有效更新；参考和候选共用由该参考构造的只读锚点与观测教师。恢复共享状态时保留客户端local补全模块，防止候选评分悄悄切换私有参数。

## 3. 通信边界

上传内容不含原始样本、单样本表示、锚点、样本ID、校准关系矩阵或EF残差。普通共享更新可稀疏编码；原型聚合仍使用真实观测软计数和共同Hungarian排列。

统计量是编码载荷字节，不是实测网络流量或延迟。当前没有服务端下行压缩；下行字节按实际需要共享的模型状态计算，local参数排除。

## 4. 比较与结果保存

新实验必须写入新版本目录，完整/缺失各率保持同一压缩选择。比较补全方法时尤其要检查共享参数数量与绝对字节预算；相同budget_ratio不一定代表不同参数规模下的相同预算。

`system/run_compression.py` 保留Stage＋EF与同预算Top-k＋EF等显式对照，默认输出 `results-补全聚类-压缩`。统一缺失矩阵 `system/run_incomplete.py` 通过 `--compression none|stage_ef|topk_ef` 选择通信方式，压缩预算统一从关闭补全的基线共享模型计算。命令见 [README](D:/Project/Python/研究生毕设/FDL-scheme-1/README.md)。

输出携带completion-v1版本。当前仅保留 [results](D:/Project/Python/研究生毕设/FDL-scheme-1/results) 中的 175 次无压缩实验，旧压缩和其他历史性能记录已删除。本批不包含压缩对照，不能用来宣布压缩收益；后续压缩实验应另选输出目录。
